# Peças impressas em 3D

Modeladas no **Autodesk Fusion 360**, fatiadas no **Bambu Studio** e impressas em **PLA Básico** na **Bambu Lab A1** do HEartLab.

| Pasta | Conteúdo |
|---|---|
| `fusion360/` | Modelos editáveis (`.f3d`) |
| `stl/` | Malhas para impressão (`.stl`) |
| `bambu_studio/` | Projetos fatiados (`.3mf`) |
